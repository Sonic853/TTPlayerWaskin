# 内置默认皮肤与资源回退

## 默认条目

`resources/base-2.91.wsz` 原样复制自用户提供的 `Skin/waskin/base-2.91.wsz`，以 RCDATA 资源嵌入 `ttp_waskin.dll`。SHA-256：

```text
0166fb878cd41de07e1cc51067525ccd3f055b94dc3c227d61124fe528788f6f
```

压缩包在内存中读取，使用与外部 WSZ 相同的 ZIP、CRC、BMP 解码和绘制实现，不生成临时 WSZ。原包没有 `skininfo.xml` 或作者说明，默认条目的作者留空。该素材保留原包来源，不将其声明为本项目自行创作的图像。

插件通过 ABI v1 的可选尾字段 `default_package` 声明 `@default.wsz`。这是提供方目录中的保留虚拟文件名，`probe` 返回显示名称 `<默认皮肤>`。宿主只处理通用的列表、预览、应用、配置和删除保护，未加入 WSZ 资源解析。

- 右键皮肤菜单的 Winamp 子菜单、选项皮肤页的 Winamp 列表均将默认条目放在首位。
- 没有 `Skin/waskin` 目录或外部 WSZ 时，默认条目仍然可用。
- 不能删除默认条目，也不能导入同名 `@default.wsz` 覆盖它。
- 配置 `Skin/CustomPackageName` 保存 `waskin\@default.wsz`；窗口状态及样式保存于 `Skin/waskin/@default.wsz.xml`，需要时创建父目录。
- 原生皮肤选择仍独立保存。选择原生皮肤时清空插件选择；两版播放器共用同一 DLL。
- 旧版接口按结构体大小协商。旧宿主可使用新版 DLL 的资源回退；要在列表中显示内置默认条目，需要同步更新宿主。

## 资源回退

已支持的主窗口、均衡器、播放列表、视频窗口使用以下资源优先级：

1. 所选 WSZ 内有效的对应位图。
2. 位图缺失或不能解码时，使用内置 base 皮肤的对应位图。
3. 只有 base 包自身未提供的资源才保留程序绘制的最后回退。

回退不替换有效但尺寸较小的位图。此类图集可能是作者刻意省略按钮行，沿用现有 Winamp 裁剪行为。折叠、调整尺寸、按钮按下等状态复用同一资源选择流程。原有缺少 balance 图时复用 volume 图、优先使用 nums_ex 的经典资源规则保留。

播放列表配置以 base 默认值为底，再叠加所选包的 `pledit.txt`；有自己的颜色、字体和窗口区域时保留其设置。缺失的可视化调色板及光标也使用 base 资源。歌词内容和编辑功能继续由千千静听提供，视频窗口边框由插件绘制。

缺失窗口资源与无效压缩包分别处理：CRC、ZIP 结构错误、现代 `skin.xml` 包，以及没有任何有效经典位图的外部包仍被拒绝，不伪装成成功加载的默认皮肤。现代 WAL 和尚未实现的 Winamp 窗口不因新增默认素材而自动获得支持。

## 本地验证

测试放在宿主的 `tests/waskin`，不纳入源码发布包或 Actions：

- 原始外部 base 包与内置默认包的四个窗口逐像素比较。
- 缺失／损坏 EQ、播放列表、视频图集时，比较完整窗口、调整尺寸和折叠状态。
- 保留现有短图集、损坏压缩包、旧 ABI 边界和连续切换资源释放回归。
- 两版宿主验证无外部文件时的目录列表、预览、应用、删除保护、配置保存及启动恢复。
- DLL 和旧系统宿主执行 XP／Win7 静态导入审计；这不等同于在 XP／Win7 真机运行。
