# WSZ 控件修复与千千静听功能替代表

本次按 [WSZ 控件分析的实施顺序](WSZ_CONTROL_PARSING.md#12-建议实施顺序与边界) 修正。业务优先调用重建版已经恢复的千千静听实现；DLL 负责资源、布局、绘制、命中和交互状态。

这是一份实现状态表。原分析文档记录的是修复前状态，不能继续把其中的“当前 DLL 缺失”当成本次结果。

## 1. 已修复的显示与输入

## 2. 功能替代表

| Winamp 控件／功能 | 千千静听替代 | 入口及行为 |
| --- | --- | --- |
| 主窗口与列表的播放、暂停、停止、上一首、下一首、打开 | 已有播放与文件导入逻辑 | `InvokeSkinAction`、`Stop`、`SelectRelative`、`ChooseFiles` |
| 随机／重复 | 千千的五种播放模式 | `SetPlaybackMode`；随机内部索引、5000 首阈值和旧系统单份策略保持由宿主管理 |
| 时间、音量、平衡、进度 | 原生设置与音频引擎 | 不新建音频引擎或独立播放位置 |
| EQ On、Presets、十段／前级 | 原生 EQ 开关、预设、设置和 DSP | `HandleEqualizerCommand`、`ShowEqualizerProfileMenu`、`SetEqualizerSliderValue`；沿用整数 -12…12、禁用门控和自定义预设保存；按段编号映射，不声称 WSZ 中的频率标签与千千 DSP 中心频率逐项相同 |
| EQ 三个快捷区 | 原生十段参数设置 | +12／0／-12，前级保持原值 |
| ADD | 原生“添加”菜单 | 工具栏菜单 0：文件、文件夹、本地搜索、URL 等，沿用原生对话框 |
| REM | 原生“删除”菜单 | 工具栏菜单 1：选中、重复、错误、清空等，保留原生确认与删除规则 |
| SEL | 原生“编辑”菜单 | 工具栏菜单 5：剪切／复制／粘贴、跨列表移动／复制、全选／反选等 |
| MISC | 原生“排序”菜单 | 工具栏菜单 3；查找、模式等其余入口仍可由空白处的原生列表菜单访问 |
| LIST | 原生“列表”菜单 | 工具栏菜单 2：新建、添加、打开、保存、删除、媒体库模式等 |
| 列表行右键 | 原生单项／多项菜单 | 由 DLL 提供命中行号，宿主按真正选中项调用 `PreparePlaylistMenu` 和原生菜单绘制 |
| 列表多选／删除 | 原生选择集合与删除逻辑 | `SelectPlaylistRow`、`DeleteSelectedPlaylistRows`；不会因单击选择而开始播放 |
| 列表内部拖动／Ctrl 复制 | 原生重排与导入提交路径 | 从 `FinishPlaylistTrackDrag` 提取共用的 `ReorderSelectedPlaylistRows`；维持播放条目身份与选中集合；媒体库查询列表继续禁止重排 |
| 外部音频拖入列表 | 原生 OLE 文件导入与批量提交 | DLL 返回可见列表的插入行并绘制提示线；宿主在该行导入，保留文件顺序、曲目身份及原有信息读取流程 |
| 频谱／示波器等 | 千千原生分析与效果功能 | 频谱由 DLL 使用 Winamp 默认经典样式、完整 24 色和峰值动画，复用宿主 FFT 快照；其余效果继续调用原生 `VisualRuntime`，详见 [频谱修复](CLASSIC_SPECTRUM.md) |
| 可视化左键／右键 | 原生效果切换／菜单 | `SetVisualType`、`ShowVisualContextMenu`；包含千千已有的梦幻、频谱、波形、封面能力 |
| 选项、置顶、歌曲属性 | 原生窗口和命令 | 不把 `genex.bmp` 绘制逻辑搬入选项对话框 |
| 主菜单、皮肤、窗口开关 | 现有菜单与窗口系统 | 原生／Winamp 分开保存、歌词原生皮肤回退、插件缺失时隐藏 Winamp 入口均保留 |
| 吸附、分离、窗口随动、尺寸吸附 | 千千原生窗口拖动 | 同步回调；宿主接管调整尺寸时优先保留原生自由缩放与磁性边缘；无拖动回调的旧宿主才使用 DLL 的 25×29 尺寸步进 |

五组按钮使用千千弹出菜单，并非 Winamp 自绘的纵向展开条。频谱已改为 DLL 的经典逐行配色与动画，使用完整 `viscolor.txt`；其它效果继续使用千千绘制。皮肤颜色仅对当前绘制生效，不写入用户的可视化设置。

### 进度拖拽与列表图标修复（2026-09-19）

- 进度释放命令 `TTP_SKIN_SEEK` 改为宿主 `SeekWithoutFade()`，与千千原生进度条释放路径一致。此前误用普通 `Seek()`，启用定位淡化时会先淡出再定位。播放与暂停状态均保留，普通和折叠进度条共用此修复。
- Winamp `draw_pe.cpp::draw_pl` 从 `pledit.bmp` 的 `(0,72,125,38)` 和 `(126,72,150,38)` 绘制底部，常驻按钮图标已经包含在其中。`y=111/130/149` 区域属于 `draw_pe_addbut/rembut/selbut/miscbut/iobut` 的展开菜单；此前将 `y=149` 常态覆盖到底部，导致皮肤自带图标被菜单文字替换。
- 删除该覆盖，保留完整底图和原生菜单功能；按钮命中顶部修正为 `height-30`。缺图后备按钮也改为直接画在底部图集中，使用项目自绘图标。
- 本地像素回归在旧 DLL 上复现覆盖问题，新 DLL 通过完整图集、仅含底图的短图集、按钮按下与列表加宽验证。两版宿主通过普通／折叠模式的真实 DLL 消息链定位测试，原生进度回归通过。

### 外部文件拖入位置修复（2026-09-21）

此前 OLE 拖放仍通过隐藏的原生 `PlayLists`／`Files` 子控件命中。其坐标、16 像素行高和
滚动位置与 DLL 的可见列表不同，还会把 Winamp 列表左侧误当成原生目录栏。

新增可选 `playlist_drop` 接口，由 DLL 按播放列表客户区、实际字体行高及自己的滚动位置
计算插入行。拖到曲目行时插入该行之前，列表内尾部空白追加；折叠时追加，参照
Winamp `pledit.cpp` 的 `WM_DROPFILES` 分支。普通模式的边框、滚动条和底部按钮不作为曲目投放区。
进入／移动使用该接口绘制插入线，松手重新查询最终位置；移出、取消或完成时清除提示。
调整窗口大小或滚动后，即使尚未重绘也使用与下一帧一致的可见起始行。

文件提取、目录／播放列表展开、批量插入及曲目信息读取仍复用宿主代码；
Winamp 布局参数全部留在 DLL。新接口按完整尾部长度协商，旧接口前缀不变。
本地 `rebuild/tests/waskin/drop_host_tests.inc` 通过实际 OLE `CF_HDROP` 回调验证左右位置、
滚动与原生滚动不一致、移窗／缩放、多文件顺序、空列表、末尾空白、折叠追加、提示线像素和清除。
测试仅存放在本地 tests 中，不上传，不由 Actions 执行。

业务代码：[宿主桥接](../../rebuild/src/ui/player_window_skin_plugin.cpp)、[原生列表](../../rebuild/src/ui/player_window_playlist.cpp)、[原生 EQ](../../rebuild/src/ui/player_window_equalizer.cpp)、[原生可视化](../../rebuild/src/ui/player_window_visual.cpp)。原千千依据也见 [EQ 恢复说明](../../rebuild/docs/EQUALIZER_RECOVERY.md) 中的 `00429D20`、`00429EF4`、`00460AB1`；列表拖放保留原实现注释所对应的 `0048218C`／`004822AD` 规则。

## 3. 暂无等价原生替代的功能

这里的“暂无”指本次检查的原版伪代码恢复路径及当前重建版接口，没有找到可直接接入的等价能力。

| 功能 | 原因 | 本次处理 |
| --- | --- | --- |
| EQ Auto：按歌曲自动读取对应 EQ 预设 | 千千现有 EQ 是启用状态、全局预设、自定义十段和前级，没有对应的按曲目预设绑定／自动装载路径；自动增益并不等价 | Auto 保持皮肤的关闭图和不可用光标；点击只提示不可用，不触发自动增益或清零，不叠加自绘灰色覆盖 |
| Winamp／ISO 频率组切换、`eqmain_iso.bmp` 的条件选择 | 宿主仅暴露原生十段值，没有 Winamp 的可切换频率组契约；更换标签图片不能改变 DSP 中心频率 | 不新增频率模式或伪造标签对应；使用经典 `eqmain.bmp`，不启用 ISO 切换 |
| Winamp 视频窗口 | 已接入歌词、视觉效果、同屏、全屏与尺寸控制；TV 按钮切换内容 | 复用千千歌词和全屏视觉，见 [视频内容窗口](VIDEO_CONTENT.md)；不提供视频解码／电视接收 |
| Winamp 通用插件窗口、Wasabi／现代 WAL 运行时 | 千千插件与 Winamp 插件 ABI、窗口生命周期及服务接口不同 | 不加载 Winamp 插件，不接受含 `skin.xml` 的现代 WAL 包；歌词等继续使用千千原生窗口 |
| Winamp 专用浏览器、在线服务或品牌入口 | 没有相同的千千业务能力与服务契约 | 不把无关功能挂到同一图形上 |

`gen.bmp`／`genex.bmp`／`colors.ini` 对原生千千对话框的完整重着色也未加入。设置、文件选择、属性和菜单已有功能替代，继续使用原生界面；它们不应被列为“业务功能缺失”。

## 4. 资源和兼容边界

- 经典资源按文件名查找，支持分布在子目录中的资源和缺少 `main.bmp` 的部分皮肤。至少必须包含一张尺寸有效的已支持图集；只有无关文件或坏主图的包仍被拒绝。
- BMP 缺失或解码失败时按整张资源使用项目自己的 GDI 后备图；成功解码的短图按实际边界绘制，不因某个源矩形不完整而补画后备控件。没有嵌入、打包或分发 Winamp 原图。ZIP 超限、歧义重名、路径穿越、CRC 错误等校验继续生效。
- CUR 支持经尺寸、热点、DIB 格式和长度校验的经典图像；PNG 光标、超过 64 像素的光标等回退系统光标。
- C ABI 仍为 v1。`selection`、`visual`、`tip`、`resize`、`spectrum` 是按 `size` 检查的可选尾部；原始 v1 与已有尾部扩展仍可加载新 DLL，完整新增功能需配套更新 EXE。
- 插件名称、皮肤子目录和后缀已改为 DLL 声明；新版宿主要求完整声明。接口与配置变更见 [皮肤选择配置](SKIN_SELECTION.md)。
- 两个版本使用同一份 XP 兼容的 x86 `ttp_waskin.dll`。

## 5. 尚未做到像素／手势完全一致的项目

这部分是剩余兼容差异，不等于“千千没有可替代功能”。

- 列表菜单采用千千菜单外观；没有 Winamp 五组按钮的纵向位图菜单。
- 字体、标题手动拖动、扩展拉丁字母逐字形转写，以及所有特殊皮肤图集变体仍不能声称逐像素一致。控件悬停提示已按 DLL 实际命中位置实现，文案复用千千功能和快捷键；没有复制 Winamp 的全部提示文字及外观，详见 [控件提示修复](CONTROL_TOOLTIPS.md)。
- 主窗口微型按钮按下反馈与后备控件由 DLL 绘制；缺图时的项目后备图不复制 Winamp 默认皮肤的视觉设计。
- 内部多选拖动与向外拖出的 OLE 手势已接通；矩形框选尚未转接。宿主增量功能适配及拖出协议见 [fc27ad0 后适配记录](REBUILD_FC27AD0_ADAPTATION.md)。
- 窗口位置、列表尺寸、折叠／展开高度、双倍尺寸及 DLL 内滚动位置已按皮肤持久化，详见 [窗口状态修复](WINDOW_STATE.md)。
- 统计按固定预算增量更新，大列表的总时长和选中时长可能延迟一轮；不会为显示统计阻塞 UI 全量扫描。
- 皮肤常规绘制保留 100ms 定时刷新；播放中的可视化由原生分析线程额外请求插件窗口重绘，没有逐项恢复 Winamp 的全部脏矩形刷新策略。
