# Winamp 视频窗口中的歌词与视觉效果

## 使用

在 Winamp 皮肤下打开“歌词窗口”，现在显示 `video.bmp` 定义的窗口。默认内容为歌词，
与重建版已有歌词文档、播放进度、滚动、逐字高亮和字体设置共用。

视频歌词的初始配色取自当前皮肤的播放列表 `pledit.txt`：`Normal` 为普通文字，
`Current` 为当前行／卡拉 OK 高亮，`NormalBG` 为背景。先应用这些默认值，再读取该皮肤
配置中的颜色；最终统一使用“选项 → 歌词秀 → 窗口模式”的普通／加亮／背景设置。
修改选项后显示及已打开的歌词编辑器立即更新，颜色随该皮肤配置保存，重选和重启后恢复。
已有颜色配置不会被 DLL 默认值覆盖；全屏歌词使用“全屏显示”中独立设置的颜色。
切回原生皮肤时仍使用原生皮肤自己的配置。
字体、行距和歌词行为仍使用宿主设置。纵向长句会按内容宽度自动换行，横向模式保留连续滚动。

右键菜单按当前内容复用宿主的原生菜单：

- **歌词**：原生歌词菜单，保留歌词调整、搜索、编辑、显示设置等命令及其可用／勾选状态。
- **视觉效果**：原生视觉效果菜单，效果选择只修改视频窗口，不修改主窗口的小视觉效果。
- **歌词与视觉同屏**：原生歌词菜单加原生“视觉效果”子菜单。

各菜单末尾的“显示内容”子菜单保留 DLL 提供的切换与窗口大小命令：

- **歌词**。
- **视觉效果**。
- **歌词与视觉同屏**。
- **视觉效果类型**：无、梦幻、频谱分析、波形、专辑封面。

同屏布局复用“选项 → 全屏显示”的歌词占比与位置关系，支持分区与透明叠加。
视频窗口的视觉类型独立保存；点击主窗口的小频谱不会切换视频窗口内容。
内容区单击、双击均不切换模式。

歌词区域复用原生歌词输入处理。启用“拖拽歌词”后，按下并移动可预览歌词位置，
松开直接定位到对应时间；横向、纵向滚动均支持，暂停时拖拽保持暂停，不启动淡入淡出。
Escape、丢失鼠标捕获、隐藏窗口、调整窗口大小或切换内容都会取消当前拖拽。
同屏分区只在歌词区域启动拖拽，透明叠加模式按实际歌词区域命中；鼠标捕获后移出窗口仍可继续拖动。
歌词区域的滚轮遵守原生“鼠标滚轮调整歌词”设置，每格调整 500 毫秒；关闭该设置时不改变音量。
方向键复用原生歌词行定位。标题拖动仍用于移动及吸附整个窗口。

歌词菜单的编辑功能使用原生 RichEdit 与工具栏，并放入视频内容区域。
切换到纯视觉模式时隐藏编辑器，返回歌词模式时继续显示当前编辑文档。
编辑期间宿主停止绘制播放歌词，DLL 在最终输出时裁掉可见编辑器与工具栏区域。
该裁剪也覆盖 `WM_PRINTCLIENT` 和直接 DC 绘制，避免父窗口定时刷新把歌词画到编辑器上。

底部五个按钮保留皮肤提供的图像，按从左到右映射如下：

| Winamp 控件 | 重建版功能 |
| --- | --- |
| 全屏 | 以当前内容模式与视觉类型进入已有全屏功能；播放时可用，Escape 返回 |
| 100% | 内容区恢复 256×232，外框保持原始像素尺寸 |
| 200% | 内容区调整为 512×464，外框保持原始像素尺寸 |
| TV | 循环选择歌词、视觉效果、同屏 |
| 视频菜单 | 打开内容与视觉效果菜单 |

右上角关闭隐藏该窗口，右下角可调整大小；标题拖动复用宿主的吸附、分离和窗口组移动。
视频位置、尺寸、内容模式和视觉类型保存在当前皮肤的 `.wsz.xml` 独立状态中。

## 源码依据与分工

- `winamp/Src/Winamp/draw_vw.cpp`：标题的 25/100 像素拼接，11/8 像素侧边，
  38 像素底栏，五个 15×18 按钮及按下图集，`mbFG`／`mbBG` 信息文字颜色。
- DLL 的 `src/video.cpp` 负责全部视频外观、内容切换菜单、按钮命中和模式选择。
  缺少或无法解码 `video.bmp` 时使用项目自身的备用图，不打包 Winamp 原始素材。
- 宿主提供通用的有边界内容绘制和输入接口，复用 `PaintLyricControl`、`HandleLyricControlMessage` 和 `VisualRuntime`。
  视觉效果以原有全屏渲染参数工作；单独的渲染器使用现有音频采样工作线程，
  不修改主窗口的视觉类型，不复制歌词解析器。
- 原生内容菜单由宿主沿用资源 143／145／148 及原有状态准备逻辑，“显示内容”子菜单由 DLL 创建。
  宿主重新映射插件菜单命令，避免与原生命令冲突；原生歌词命令使用已有分发路径，
  原生视觉效果命令通过通用内容状态接口更新 DLL 的独立效果。菜单循环期间 DLL 没有活动调用栈，
  换肤不会使插件仍在执行的成员函数引用失效。
- ABI v1 追加可选 `content`、`lyrics`、`handles`、`menu`、`content_input`、`content_state`，按完整字段长度协商。
  老宿主或无内容回调时仍保留原来的三个插件窗口和原生歌词窗口。
  已有 `content` 的旧宿主继续显示视频；仅缺少新增的原生交互扩展。
  `TTP_SKIN_CONTENT_CHILD` 属性标记由宿主管理的编辑器子窗口，使其不被皮肤的原生控件隐藏逻辑覆盖。
- 可选 `lyric_colors` 查询返回 DLL 提供的普通／高亮／背景默认值，`window=nullptr` 可在 attach 前查询。
  宿主将它们作为皮肤配置的合并底值；绘制时不再绕过设置直接查询 DLL。旧插件未提供该完整字段时沿用宿主配色。
  皮肤格式、`pledit.txt` 路径和颜色解析仍留在 DLL 内。
- 原版伪代码 `004425F7`／`00442671` 定义捕获、拖拽及松开定位，`00442A97` 定义滚轮时间调整，
  `004427B1`／`00449E98` 与 `00458020` 定义歌词／视觉菜单。视频窗口是普通窗口，使用普通窗口菜单，
  真正全屏时仍走原有全屏菜单裁剪逻辑。
- 原有布局版本 1 可读取；版本 2 额外保存视频状态。普通版和 XP／Win7 版共用一个 DLL。

这里复用的是音频可视化和歌词显示，没有添加视频解码或电视接收功能。

## 验证

本地 `rebuild/tests/waskin/` 覆盖：

- 视频标题、侧边、底栏及全部五个按钮的普通／按下源像素，任意尺寸锚点。
- 十五组旧／截断／新接口长度组合，结构体后方保护页检测越界读取。
- 默认歌词、菜单与按钮切换、内容区点击不切换、独立效果选择。
- 歌词与原生渲染逐像素比较、输出边界、同屏分区及透明叠加。
- 两种歌词模式 × 两个拖拽方向 × 播放／暂停的原生定位时间对照，预览不跳转、松开不淡入淡出。
- 捕获、移出区域继续拖拽、取消、拖拽开关、分区／叠加命中、滚轮时间调整及禁止音量串入。
- 三种内容的原生菜单文本／命令／状态／子菜单完整对照、视频独立效果分发、原生编辑器显示与模式切换。
- 原生／插件长句实际像素、换行后的拖拽时间、跨行卡拉 OK、字体／宽度重排和 Unicode 边界。
- 编辑状态连续 30 次父窗口输出不覆盖 RichEdit 区域，宿主不再生成播放歌词画面。
- 播放列表默认颜色、真实“歌词秀”颜色选择器、编辑器即时更新及保留编辑内容／修改标记。
- 自定义颜色重选／重启恢复、全屏独立配色及 attach 前默认颜色查询。
- 主窗口视觉关闭时视频 FFT 仍更新，全屏返回后立即隐藏原生子控件。
- 同皮肤重选、重新创建程序、窗口位置／尺寸／模式持久化及切回原生。
