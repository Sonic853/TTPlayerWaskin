## 调用路径

### 桌面歌词和窗口位置

WSZ 主窗口、WAL 主布局均通过 `host.drag` 进入宿主拖动组。`659abe2` 对隐藏歌词 HWND 的移动记录因此直接生效。WSZ 视频窗口及 WAL 的独立后备歌词窗口仍由插件设置位置和尺寸，宿主不会把原生皮肤的窗口尺寸覆盖上去。

检查关注：连续进入桌面模式不把隐藏 HWND 误记为用户关闭歌词；未吸附窗口不跟随；已吸附窗口同步移动；保存配置、重新排列、返回窗口模式后位置和可见性保持正确。

### 更新功能

- 更新通知的选项入口为 `0x7f4`，定位“常规 → 软件更新”子页；插件不截获此消息。
- 主程序自己的 UI 计时器继续执行后台结果轮询，与 WSZ/WAL 的绘制计时器编号分开。
- 更新器用 `WM_APP + 0x351` 请求正常退出。歌词保存中宿主拒绝请求；允许时转发 `WM_CLOSE(wParam=1)`，不被“关闭时最小化到系统栏”设置变成隐藏操作。
- 默认不检查时，皮肤加载和本地兼容测试不触发更新网络请求。
- 更新器、HTTPS、通知窗口和设置属于主程序；无需在皮肤 DLL 中新增更新控制或 Wasabi 服务。
