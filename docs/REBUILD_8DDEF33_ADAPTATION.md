# rebuild 8ddef33 播放列表行为适配

日期：2026-09-27。

本次明确包含 `rebuild 8ddef33` 本身。核查时本地 HEAD 与已缓存的 origin/master 均为该提交，没有更晚的本地记录；未将其解释为远端已重新同步。插件基准为 `waskin 6b3f3ce`。

## 对照范围

| 宿主改动 | 插件情况及处理 |
| --- | --- |
| 原生 Files 右键前同步选择、焦点和锚点 | WSZ 与 WAL 自绘列表不会经过该通知，新增可选宿主菜单回调，由宿主应用同样的右键规则。 |
| 原生滚轮交给 SysListView32 | 插件仍自行接收滚轮，统一支持系统行数、整页、高精度累计、Ctrl／Shift 过滤及末页边界。 |
| 拖动区域上下扩展 2 像素，底行继续向下滚动 | WSZ 内部移动及 WSZ／WAL 的 OLE 拖入使用统一边缘规则；WAL 仍核查最上层可见控件，关闭的抽屉不能隔着主界面接收列表拖入。 |
| 松手位置复核、取消和禁用拖放 | WSZ 松手时重新计算插入位置，避免最后一个移动消息留下的旧插入点；两种皮肤在禁用拖放时不启动重排或 OLE。 |
| 键盘菜单定位在行中央 | 插件提供实际绘制的行坐标。WAL 内嵌列表获得输入后，键盘菜单走歌曲列表，歌词区域仍走内容菜单。 |
| 列表目录重命名完成及首击消费 | 插件没有单独实现目录编辑器，继续使用宿主已有的目录／媒体库路径，无需复制重命名代码。 |

标题区、歌曲文字显示、MAKI 脚本运行器和播放模式不在此次变更范围。

## 原生右键语义

依据 `rebuild/docs/PLAYLIST_MOUSE_BEHAVIOR_AUDIT.md` 中的原版伪代码定位及相同样式 `SysListView32` 对照。原版 `00488FEF` 使用系统控件已经建立的选择，而不是把右键等同于左键。

| 输入 | 选择集合 | 当前行／锚点 |
| --- | --- | --- |
| 普通右键已选行 | 保留多选 | 两者移到点击行 |
| 普通右键未选行 | 仅选中点击行 | 两者移到点击行 |
| 普通右键空白 | 清空选中集合 | 保留当前行和锚点 |
| Ctrl 右键歌曲 | 保留选择，不切换选中状态 | 保留当前行，锚点移到点击行 |
| Shift 或 Ctrl＋Shift 右键 | 保留选择 | 保留当前行和锚点 |
| 键盘菜单 | 保留选择 | 不重新命中鼠标位置 |

菜单使用宿主原有资源、样式及单曲／多曲命令。右键更新不会触发“播放跟随光标”。修饰键与菜单坐标在事件发生时复制，不在消息队列处理时重新读取。

## 滚轮与拖动

- 一整格滚轮以 `WHEEL_DELTA` 为单位累计；WAL 原先直接整除导致半格滚轮丢失。
- 读取 `SPI_GETWHEELSCROLLLINES`；0 表示不滚动；整页及超过页面高度的行数保留一行重叠。
- Ctrl／Shift 滚轮不移动列表、不修改累计余量、不转成音量调整。
- 当次滚动立即限制在最后一整页，避免等待绘制才限位，导致下一次滚轮或文件拖入读到过大的顶部索引。
- 滚轮保持原有输入焦点；插件已有的未聚焦悬停路由继续有效。
- 插入点查询不改变滚动位置；拖入预览才处理边缘滚动。松手按当前坐标重新查询，取消操作不执行移动。
- 外部文件仍使用宿主 CF_HDROP，插件不复制文件导入、播放列表持久化或 OLE 数据对象实现。

## ABI 与交付

ABI 仍为 v1，在 `TtpSkinHost` 尾部追加按 `size` 协商的 `playlist_context`。`TtpSkinPlaylistContext` 只包含固定布局数据；宿主复制后排队，菜单始终在 DLL 回调返回后打开，不跨模块持有调用方缓冲区。原有字段与命令编号不移动，`EQ_VALUE=100` 不变。

`option(TTP_SKIN_PLAYLIST_DRAG_ENABLED)` 查询宿主拖放开关。旧宿主返回 -1 时沿用旧版兼容行为，缺少新菜单回调时退回原 `LIST_MENU`。要获得本次完整语义，应同时更新主程序和 DLL。两份公开 SDK 保持相同内容。

本地交付使用通用 x86 Release：

- `rebuild/build/Release/AddIn/ttp_waskin.dll`：XP、Win7 和新系统共用。
- `rebuild/build/Release/TTPlayerRebuild-2026.09.27.zip`：主程序、更新器、经验证的 HTTPS 组件与内部校验表，皮肤插件仍单独放在 AddIn。
- `rebuild/out/test-artifacts/8ddef33-adaptation/`：旧产物备份、失败基线、回归日志和最终产物哈希。
