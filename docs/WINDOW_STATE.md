# 皮肤窗口布局持久化

## 原因

宿主已有按皮肤保存的 `.wsz.xml`，但原先存在三处断点：

1. 运行中重新选择插件皮肤只保存上一份配置，没有加载目标皮肤配置。
2. DLL 每次 `Attach` 都重置主窗口、列表和 EQ 的坐标与尺寸，覆盖启动时宿主读到的矩形。
3. 折叠、双倍尺寸、折叠前高度和列表滚动位置只存在于 DLL 实例内，销毁实例后丢失。

## 实现

- `TtpSkinPlugin` 的可选尾部增加 `layout` 回调，使用 `TtpSkinLayout` 传递三个屏幕矩形和 DLL 自己解释的版本化状态文字；不传递 C++ 对象或跨模块分配的内存。
- 宿主只负责读取／写入该包的 `.wsz.xml` 和调用回调。矩形仍使用 `PlayerWnd`、`PlayListWnd`、`EqualizerWnd`；DLL 状态保存为 `PluginSkin/State`。原生后备皮肤的 `.skn.xml` 保持独立。
- 换肤顺序为：捕获并保存旧皮肤，读取新皮肤配置，把布局交给新实例，然后绑定窗口。重新选择同一个皮肤也执行此流程。
- DLL 恢复三个窗口的位置、列表大小、三窗折叠状态、主窗／EQ 双倍尺寸、折叠前高度和列表滚动位置。辅助窗口显隐继续由宿主原有配置管理。
- 退出时保存同一份配置。DLL 缓存最近一次非最小化布局，最小化产生的 `-32000` 坐标不会覆盖它。解绑后重新绑定同一实例也保留缓存，供加载失败回滚使用。
- 已有配置只有矩形时，尽量推导双倍尺寸和折叠状态；旧版从未保存的折叠前列表高度无法追溯，首次使用默认展开高度，此后会正常保存。
- 不完整配置的空缺矩形使用初始布局，不继承上一插件的折叠尺寸。损坏或未知版本的 DLL 状态回退为可用的矩形；读取时校验尺寸和数字范围。

DLL 不直接读写配置文件。布局解释、尺寸约束及状态版本均留在 DLL；探测皮肤和生成预览不写配置。

## 兼容与验证

ABI 仍为 v1，新增回调按接口大小协商。宿主仍识别没有 `layout` 回调的旧插件；完整修复需要同时更新 EXE 和 `AddIn/ttp_waskin.dll`。普通版和 XP／Win7 版继续使用同一 DLL。

本地测试覆盖同皮肤重选、A/B 皮肤独立布局、原生／插件切换、三窗折叠及展开高度、双倍尺寸、辅助窗口显隐、最小化保存后重新创建播放器并从磁盘恢复，以及不完整／无效状态和旧矩形恢复。保留悬停、吸附和定位等既有回归。

测试代码仅在 `rebuild/tests/waskin`，不上传、不打包，Actions 不增加测试步骤。运行测试使用当前 Windows；旧系统另外检查静态导入，未进行 XP／Win7 真机或虚拟机测试。
